Someone sent you a special Bloom.

Open BloomingBitz to discover it, one step at a time.

Install, then tap again

If you haven’t installed BloomingBitz, look for it in the App Store. If it isn’t available yet, keep the original invitation until launch.

After installing, return to the original message and tap the invitation again. If the link stays in a browser, try opening the original message in Messages or Safari.

Or use a Bloom Code

Copy the code, then open BloomingBitz → Discover the Message and paste it. Walking reveals the Bloom; opening this page does not reveal the message.
